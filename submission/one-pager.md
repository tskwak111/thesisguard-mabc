# One Pager — Thesis Change Detector (예선)

## Thesis Change Detector — 오늘 내 투자논지에서 달라진 것

> **오늘 주가가 아니라, 내가 산 이유가 달라졌는지를 추적합니다.**

---

## 문제

개인투자자는 매일 뉴스·공시·시장지표를 반복해서 확인한다. 하지만 정보는 너무 많고, 중복되고, 흩어져 있다. 같은 보도자료를 20개 언론이 전재한 날, 기사 20건을 읽어도 새로운 사실은 1~2개뿐이다. 결정적으로, **처음 종목을 산 이유(투자논지)와 오늘의 새 정보를 체계적으로 비교하는 사람은 거의 없다.**

## 핵심 통찰

사용자에게 필요한 것은 더 많은 뉴스가 아니라 이 질문의 답이다:

> "오늘 새로 확인된 정보가, 내가 세운 투자논지를 실제로 바꾸는가?"

## 해결 방식

1. 사용자의 투자논지를 **핵심 가정 · 강화 조건 · 재검토 조건**으로 구조화해 등록
2. 오늘의 공시·뉴스·시장지표를 **사건 단위로 중복 제거** (전재 기사 20건 = 사건 1건)
3. 이전 상태와 비교해 **신규 정보만 선별** (반복·재노출 기사 제외)
4. 논지별 **강화 · 약화 · 모순** 연결 및 반대 증거 탐지
5. 결정론적 게이트를 통과한 상태 변화와 포트폴리오 공통 위험을 **근거(source ID)와 함께** 브리핑

## 왜 단순 요약기가 아니라 에이전트인가

한 번의 요약으로 끝나지 않는다. 다음 파이프라인이 매일 누적된다:

> 이전 상태 기억 → 자료 통합 → 사건 중복 제거 → 개인 논지 연결 → 반대 증거 탐지 → 보수적 상태 판정 → Skeptic 검증 → 근거 연결 브리핑

상태는 6단계(강화됨/유지/관찰 필요/약화됨/재검토 필요/판단 보류)로 관리되며, 모든 변화는 감사 원장에 기록되어 나중에 "왜 그렇게 판단했는가"를 추적할 수 있다.

## 입력 → 판단 → 결과 흐름

```
Daily Evidence Pack 입력            처리                          출력
[포트폴리오]                 ┌→ 사건 추출·중복 제거 ─┐      8섹션 고정 브리핑
[투자논지 카드]        ────→  ├→ 신규성 판정        ─┼───→   · 어제와 달라진 핵심 변화 최대 3개
[이전 상태]            ────→  ├→ 논지 연결·방향 판정 ─│       · 종목별 6단계 상태 + 근거
[시장·기업 자료]              └→ 결정론적 상태 게이트 ─┘      · 포트폴리오 공통 위험
                                                              · 정보 품질 + 안전 안내
```

## 차별화

| 기존 서비스 | ThesisGuard |
|---|---|
| "오늘 무슨 뉴스가 나왔나" | "그중 내 논지에 새롭게 중요한 것은 무엇인가" |
| 기사 나열 | 전재 기사 통합 후 진짜 신규 사건만 |
| 당일 등락 중심 | 내가 산 이유가 유효한지의 누적 추적 |
| 확신에 찬 결론 | 증거 없으면 "없다"고 정직하게 출력 |

## 모두를 이롭게 하는 가치

- 반복 정보 확인 시간 절감 (기사 수가 아니라 사건 수로 소비)
- 자극적인 당일 뉴스보다 근거 중심 판단 지원
- 투자 이유와 위험조건의 명확한 기록 — 종잣돈보다 종잣돈의 '이유'를 지키는 습관
- 여러 종목에 숨은 공통 위험(테마 집중 등) 인지
- 교육용: 리서치 스터디·투자동아리의 근거 기반 분석 훈련 도구로 활용 가능

## 안전 경계 (제품 원칙)

- 매수·매도·목표가·비중 지시 **구조적으로 금지** (출력 필터 + Skeptic 검증 이중 차단)
- 사실 / 해석 / 미확인 분리 표기, 모든 핵심 주장에 source ID 연결
- 커뮤니티 루머(Tier D)는 상태 변경 근거에서 배제
- 외부 문서 속 지시문(프롬프트 인젝션)은 데이터로만 처리
- 새로운 정보가 없는 날은 억지 결론 대신 "증거 없음"을 정상 출력

## 예선 데모 결과 (가상 데이터 기준)

- 문서 7건 → 사건 2건 통합, 무관 1건 제외
- 공식 공시 1건이 핵심 가정 직접 강화 → 보유종목 "강화됨" (근거 S001)
- 동일 사건 전재 6건 → 독립 증거 1건으로 계산
- 강한 상반 증거 동시 발생 → "판단 보류"로 보수 처리
- 무변화 시나리오 → 억지 결론 없이 "새로운 증거 없음"

*데모 수치는 저장소 `examples/` 의 가상 fixture 실행 결과이며 실제 시장 데이터가 아닙니다.*
