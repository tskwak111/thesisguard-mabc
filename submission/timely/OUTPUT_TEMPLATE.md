## source ID 표기 예

- 문장 끝 괄호: `…계약을 체결했다 (S001)`
- 목록형: `- 근거 출처: S001, S003`
- 하나의 주장에 복수 출처 가능. 단, 같은 사건의 전재 기사는 대표 출처 하나로 표기하고 나머지는 `※ 전재`로만 참고 표시.
