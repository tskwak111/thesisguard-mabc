# Daily Evidence Pack 입력 템플릿

아래 템플릿을 복사해 `[ ]`를 채워 Timely AI의 사용자 입력 영역에 붙여 넣으십시오.
모든 예시 값은 **가상 데이터(FICTIONAL TEST DATA)**이며 실제 종목·기사가 아닙니다.

---

```markdown
[PORTFOLIO]
- 가상전자 / KA000000 / 보유 / 비중 40%
- 가상전력 / KB000000 / 관심 / 비중 -

[THESIS_CARDS]
## 가상전자 (KA000000)
- 논지 요약: AI 서버 수요 증가로 고부가 메모리 매출 비중 상승
- 핵심 가정: AI 데이터센터 설비투자가 중기적으로 증가한다. [태그: ai_capex]
- 강화 조건: 핵심 고객사 AI 설비투자 가이던스 상향 [태그: guidance_up]
- 재검토 조건: AI 설비투자 축소 또는 고부가 수요 둔화 공식 발표 [태그: capex_cut]
- 추적 항목: 고객사 CAPEX 가이던스, 메모리 가격, 영업이익률

- 논지 요약: AI 데이터센터 확장에 따른 전력수요 증가
- 핵심 가정: 데이터센터 전력 수요가 증가한다. [태그: dc_power]
- 강화 조건: 데이터센터 건설 인허가 확대 [태그: permit_up]
- 재검토 조건: 데이터센터 투자 둔화 공식 발표 [태그: dc_slowdown]

  NEGATIVE로 표시된 지표는 해당 위험요인의 "오늘 악화" 판정에만 사용되며, 절대 매매 근거로 변환되지 않습니다.
```

## 작성 요령

1. **source ID는 반드시 부여**하세요(S001, S002…). ID 없는 자료는 브리핑 근거로 사용되지 않습니다.
2. **등급(A/B/C/D)** 을 정확히 표기하세요. D(커뮤니티·루머)는 상태 판정에서 제외됩니다.
3. 같은 사건을 여러 언론이 다뤘다면 **모두 넣어도 됩니다.** 에이전트가 하나의 사건으로 묶습니다.
4. 이전 상태를 모르면 `첫 실행`이라고 명시하세요.
5. 날짜·시각은 가능한 한 KST와 함께 기재하세요.
