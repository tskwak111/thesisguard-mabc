# 결선 MVP 확장 경계 (예선 범위 밖)

예선 구현에 포함하지 않은 것과 결선에서의 선행 조건만을 정리한다.

## 결선으로 가져가지 않는 것 (영구 제외 원칙)
- 자동매매·주문 연동, 매수·매도 추천, 목표가·수익률 예측 — 제품 불변조건

## 결선 MVP 확장 목록과 선행 조건
1. 장 마감 후 자동 데이터 수집 → 데이터 공급자 라이선스 검토 선행
2. 웹 대시보드(오늘의 상황실·논지 카드·위험지도) → 사용자 인증·계정 체계 설계 선행
3. 증거 원장 DB 영속화 → 감사 로그 요구사항 정의 선행
4. 사용자 피드백 루프(관련성 순위 반영) → 반대 증거 탐지 유지 조건 명시
5. 실제 LLM 연동(Solar Open 2) → 공식 API 문서 확인 후 `PromptAnalysisEngine.complete_fn` 주입 방식으로 연결
6. 푸시 알림 → 과도한 알림 방지 게이트(§19.9) 유지 조건 포함
